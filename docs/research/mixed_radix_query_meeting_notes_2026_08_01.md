## 2026-08-04 更新：联合目标的终局判断

这部分已经整合进新版 deck 第 14--18 页，不再只是附加分析。

### 一句话结论

两个较大 SAQ segment 的确共同包含显著的事后排序修复空间，但在一组
base directions 上学到的联合代码选择，不能泛化到另一组 disjoint base
directions。因此存在的是“看完评估方向后可以利用的误差抵消”，而不是
稳定、query-unaware、可以部署的联合编码规则。

### 为什么 exact replacement 一开始看起来有希望

我们没有用 reconstruction error 直接推断 Recall，而是做了更接近排序错误
的诊断。对每个数据库 target，把某个 segment 的近似距离贡献替换成精确
距离贡献，同时保留其他所有 segment 的近似贡献，再观察原来排错的向量对
有多少恢复正确顺序。

单独替换 `192d@6b` 或 `320d@4b` segment，只修复约 43%--44% 的 inversion，
没有达到预先冻结的绝对改善标准；同时替换两者则修复 71.10%--75.57%。
这说明完整 estimator 中确有两段联合 headroom，但 exact replacement 使用了
压缩代码中不存在的真实值，只能作为上界，不能直接变成 encoder。

### 为什么需要静态分析和 cross-fit

固定 SAQ plan 后，两段的合法代码集合是 Cartesian product。reconstruction、
对未知方向的 worst-case inner-product error，以及各 segment 独立的平均误差，
都会严格分解为两个单独目标。能让它们发生联合选择的，只能是训练方向中
观察到的跨段误差相关性。

这种相关性容易产生 cancellation：训练方向上第一段误差为 `+2`、第二段为
`-2` 时，总误差为零；换一组方向后，两者可能都变成 `+2`，总误差就变成
四。因此不能在同一组方向上训练和验证，必须 cross-fit。

### 冻结实验和结果

- 只读取既有 GIST sample50k base/index，不读取 benchmark query 或 ground truth；
- 固定 32 个 target，两组各 128 个 disjoint base directions；
- 每段候选只包含 production code 和所有合法的单坐标 `+1/-1` move；
- `IND_TRAIN` 分别选择两段代码；`JOINT_TRAIN` 穷举相同候选的 Cartesian
  product；选择后在另一组 directions 上冻结评估，再交换两折；
- 通过条件是两折都比 independent 至少降低 5% MSE，并改善至少 60% target。

结果如下：

| train/eval | joint 相对 independent 的 held-out MSE 改善 | 改善 target | held-out oracle 改善 |
| --- | ---: | ---: | ---: |
| fold 0 → fold 1 | +0.0805% | 15/32 | 16.83% |
| fold 1 → fold 0 | -1.3644% | 13/32 | 15.92% |

第二折的负数表示 joint 反而更差。joint 与 independent 虽然在 29/32 和
31/32 target 上选择了不同代码，却没有稳定收益。held-out oracle 的约 16%
只能说明“看完答案以后能选得更好”，不能说明训练规则有效。

决定为 `JOINT_LOCAL_NO_GO`。不扩大邻域、不调 folds 或门槛，也不读取
benchmark queries 来救这条路线。

## 2026-08-03 更新：非相邻配对的终局判断

这部分是 8 月 1 日 deck 之后得到的新证据。下次汇报时应先讲本节，再决定
是否需要回顾后面的原始逐页材料。

### 一句话结论

非相邻配对确实明显优于固定相邻配对，但我们提出的“按经验量化误差求
最大权匹配”并没有明显优于优化乘积量化（OPQ）已有的 Eigenvalue
Allocation（按坐标方差进行分组）。
因此，这条结果不能作为新的 mixed-radix 贡献，也不足以支撑一个独立的
最大权匹配方法。

### 为什么一开始看起来是正面结果

最初的直接 Recall 实验比较最大权匹配与固定相邻配对。非相邻配对在
SIFT1M 上提高约 0.020--0.025 Recall，在 GIST1M 上提高约 0.009--0.010。
这个差距是真实且可重复的，但它只能说明 `(0,1),(2,3),...` 这样的固定
相邻分组很差。

同时，任意整数 radix 与二次幂 radix 在相同配对上的 Recall 差异仍然不
超过约 0.00057，而且正负不稳定。因此这个正面结果来自坐标重分组，而
不是原始 mixed-radix 机制。

### 与最接近已有方法的判别实验

我们随后保持坐标变换（PCA）、变换后的残差、索引、字节数、查询、候选、
分配器和查询程序全部不变，只替换坐标配对规则：

- `D_MWM`：根据每一对坐标的经验量化误差，求全局最小代价完美匹配；
- `D_EA`：使用 OPQ 已有的 Eigenvalue Allocation，根据坐标方差把强弱
  坐标分到同一大小的二维组；
- 三个预先固定的随机非相邻配对；
- 固定相邻配对作为最弱锚点。

这里的 `Recall@100` 是：真正最近的 100 个数据库向量中，最后成功找回了
多少比例。表中的“搜索 64/1,024 个单元”表示一次查询分别检查较少或较多
的粗粒度数据库区域。数值为 `D_MWM` 减去 `D_EA`；正数表示最大权匹配
略好，负数表示已有方差分组略好。

`D_MWM` 相对 `D_EA` 的 Recall@100 差异为：

| 数据集 | 搜索 64 个单元 | 搜索 1,024 个单元 |
| --- | ---: | ---: |
| SIFT1M | +0.000253 | +0.000349 |
| GIST1M | +0.000320 | -0.000160 |

预先冻结的通过标准要求：两个数据集趋势一致，并且每个数据集至少有一个
搜索范围达到 `+0.002`。实际结果不但小了约一个数量级，GIST 还出现符号
反转，所以没有通过。

这不是两个方法碰巧产生了相同配对：SIFT 的 64 对坐标中只有 2 对相同，
GIST 只有 1 对相同。它们虽然形成了非常不同的配对表，却得到几乎相同的
Recall，说明已知的简单方差分组已经解释了最大权匹配的大部分查询收益。

三个随机非相邻配对也都优于固定相邻配对，但弱于 `D_EA` 和 `D_MWM`。
这进一步说明真正稳定的现象是“不要机械地相邻配对”，而不是“必须求解
经验量化误差最大权匹配”。

### 当前应如何向老板表述

> 我们先发现，重新安排坐标配对可以明显改善 Recall。但这个结果并不是
> mixed-radix 的收益，因为允许任意整数 radix 几乎没有进一步帮助。
> 在补上最接近的已有方法后，OPQ 的方差分组已经取得与我们的最大权匹配
> 几乎相同的 Recall。最大权匹配虽然更精确地优化了训练误差，但没有形成
> 可观、稳定的查询收益。因此我们保留“固定相邻分组不合理”这个诊断，
> 但终止把当前最大权匹配当作独立研究方向继续扩展。

### 更新后的边界和决定

- 仍然成立：固定相邻 mixed-radix 在自然数据上没有有效收益。
- 仍然成立：synthetic 正例证明 mixed-radix 机制在特制数据上可以影响
  Recall，但没有证明自然数据价值。
- 新增结论：非相邻配对有价值，但它主要复现了已有“优化坐标分组”方法
  的作用。
- 终止结论：不再为当前最大权匹配扩展更复杂的已有分组对照或完整实验
  矩阵，也不把它描述为 SAQ 特有、mixed-radix 或独立系统贡献。
- 如果继续研究，需要提出机制上不同的新问题；不能仅放大当前 MWM 的
  实验规模。

## 一页问答卡

**Q：synthetic 结果这么好，为什么自然数据方向仍然关闭？**  
A：synthetic 是为了验证因果机制，数据被刻意构造成三乘五或十五乘十七。
SIFT/GIST 的分配几乎都是四乘四或十六乘十六，真实 Recall 改变也很小且
正负不稳定。

**Q：这是不是说明之前自然实验实现错了？**  
A：不是。相同 consumer 在正例中准确地产生预期 Recall 差异，在零效应
对照中又得到完全相同的排序。这反而加强了自然负结果的可信度。

**Q：为什么 reconstruction 更好不一定 Recall 更好？**  
A：reconstruction 对所有向量的平均坐标误差计分；Recall 只关心查询附近
候选的相对排序。减少远处向量误差可能降低平均误差，却不能恢复近邻次序，
甚至可能改变误差方向而让排序变差。

**Q：synthetic 正例能否作为论文主结果？**  
A：不能单独作为主结果。它证明机制不是空的，但没有证明真实数据普遍性、
性能优势或相对 PQ/OPQ 的新前沿。

**Q：下一步最合理的研究是什么？**  
A：不要再扩大当前最大权匹配的实验规模。最接近的已有对照已经说明，OPQ 的
方差分组能够解释几乎全部配对收益。下一步应该重新选择一个机制上不同、
并且能明确超过已有坐标分组方法的问题；在新假设冻结前，不运行新的大
矩阵。

**Q：最大权匹配不是比方差分组更“精确”吗？为什么仍然终止？**

A：它在训练重构误差上确实更精确，但 Recall 只关心近邻排序。SIFT 上它
比方差分组最多提高 0.000349，GIST 还有一个搜索范围下降 0.000160。更复杂
的优化目标没有转化成查询收益，算法形式更复杂本身不能构成贡献。

**Q：这是否说明非相邻配对完全没有价值？**

A：不是。非相邻配对明显优于固定相邻配对；被否定的是“当前经验量化误差
最大权匹配具有独立优势”。现有证据支持使用合理的坐标分组优化，不支持
把当前匹配器作为新方法继续包装。

**Q：两段 exact replacement 能修复七成以上排序错误，为什么还要关闭？**

A：因为 exact replacement 使用了压缩代码里没有保存的真实 segment 距离。
它回答“如果这些误差消失，最多可能怎样”，不回答“encoder 如何只用相同
字节消除它们”。真正用 base directions 学联合代码后，held-out 改善没有
通过，因此 oracle headroom 没有转化成方法。

**Q：held-out oracle 还有约 16% 收益，是不是应该扩大候选邻域？**

A：不是。held-out oracle 在看过评估 directions 后选答案，本来就会受益。
关键对照是用另一组 directions 训练后能否泛化；两折都没有达到 5%，其中
一折还变差。扩大邻域会增加事后可选答案，也可能加重过拟合，不能修复这个
因果缺口。

**Q：这是否证明所有 estimator-aware quantization 都不可能？**

A：没有。结论只覆盖冻结的两段、单坐标 `+1/-1` 候选、相同 SAQ plan、
相同存储和不增加查询工作的 base-trained joint objective。改变 estimator、
增加跨段 metadata 或提出不同表示都是新问题，需要重新比较 closest work
和完整成本，不能算当前结果的自然延伸。
